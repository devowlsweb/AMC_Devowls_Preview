# Instrucciones del proyecto

- Mantener HTML, Tailwind compilado y JavaScript; no introducir frameworks sin pedido.
- Para trabajos de interfaz, leer .agents/skills/ui-ux-pro-max/SKILL.md y docs/DESIGN.md.
- Respetar el alcance comercial: productos, materias primas y fórmulas; datos ficticios.
- Usar Lucide oficial. No crear SVG de íconos ni logos a mano.
- src/icons.js se genera desde el paquete Lucide; modificar los alias en scripts/build.mjs.
- Conservar compatibilidad con GitHub Pages y rutas relativas.
- Antes de entregar cambios funcionales, ejecutar npm test y npm run build.
- No afirmar autenticación, permisos reales ni persistencia compartida: la demo usa localStorage y perfiles visuales.
